# Episode 1 of Steph's Coding Adventures with Claude 🚀

## Maze Runner: A Reinforcement Learning Based Game that uses Q-learning to teach a robot agent how to manuveure a maze that the user builds.

Steps to play:
-- click and drag on the canvas to draw walls
-- click the train button to train the robot agent to manuveure the walls
-- click the "watch it walk button to watch your robot move and rate how smart it is!


The music starts when you click the screen. You can pause the music if you like.
